INSTAGERAM - Portable Campaign Manager
======================================

Portable executable:
Instageram.exe

All folders and data are relative to the folder containing Instageram.exe.

Important files:
- config\settings.json           (created on first run)
- config\settings.template.json  (defaults for new installations)
- data\database.db
- logs\application.log
- data\backups\
- exports\

This application does not store Instagram passwords or tokens.
It does not create fake followers, fake accounts, follow/unfollow automation,
engagement manipulation, or Instagram restriction bypassing.

Any future online connection must use official authorized APIs.
